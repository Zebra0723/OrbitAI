Commands

Everything it understands, and what happens when it does. Anything not here goes to Claude, which writes a one-line command and reads it back before running it.

What waits for a yes

Straight away

Volume, brightness, dark mode, music, screenshots, opening apps, timers, notes, reminders, questions, anything that reads something out. Confirming "volume up" out loud takes longer than the key would have.

Read back first

Sending a message, sending mail, placing a call, dispatching Claude, quitting an app, emptying the trash, turning Wi-Fi off, sleep, restart, shut down, typing into whatever is in front, and every command Claude writes.

Say no, cancel, or never mind to drop it. Say nothing for twelve seconds and it drops itself. A confirmation expires after ten minutes, so a late yes can't fire an old command.
