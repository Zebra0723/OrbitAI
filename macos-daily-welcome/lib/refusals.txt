# What Orbit says to a voice it will not take orders from.
#
# Not a list of finished lines - a set of interchangeable ones. Every
# entry here is a COMPLETE SENTENCE, which is the whole trick: any
# opener, any reason and any redirect can be joined in that order and
# the result is always grammatical. Thirty-five openers, thirty-four
# reasons and twenty-four redirects is a little over twenty-eight
# thousand distinct refusals, which is enough that nobody will hear the
# same one twice.
#
# The reason slot is the one that matters. Every line in it says, in one
# way or another, that the voice is not enrolled - so however the
# sentence is assembled, the person being refused is told what is
# actually wrong. Being teased and being confused are different
# experiences and only one of them is any fun.
#
# Rude, and harmless. They are about the situation - you are not on the
# list - and never about the person. Keep it that way if you add your
# own; anything here is said out loud to whoever is standing there.
#
# Sections are "# name" and lines are lines. Blank lines and lines
# starting with # are ignored, so add your own freely.
